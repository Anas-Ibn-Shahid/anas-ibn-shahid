# Anas Ibn Shahid

### Building Intelligence. Solving Real-World Problems.

I am driven by a curiosity to understand how intelligent systems work and a determination to build technology that makes a difference.

- Autonomous Systems & Robotics
- Intelligent Decision-Making Systems

**Learning. Experimenting. Building. Evolving.**
